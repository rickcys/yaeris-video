## Full script (verbatim, 8 lines)

1. Most developers using Crawl API never realize their own API key already does more than they're actually using it for.
2. There are two fundamentally different access paths built into that one key, and most accounts only ever touch one.
3. The REST half: wire the key into a backend call, get structured data back. Standard, simple, where most integrations stop.
4. The MCP half: the exact same key, used by an AI agent to call the crawler directly, no second account, no second token to manage.
5. The tell is simple: check how your agent currently gets web data. If someone's manually scraping it and feeding it in by hand, that's a sign the MCP half has never been touched.
6. Same credits, same automatic three-tier escalation, same robots.txt compliance, whichever path you use.
7. One integration already covers two genuinely different use cases, a backend and an agent, and most accounts are only ever using it for one of them.
