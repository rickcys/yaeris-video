The old way: a custom integration, hand-built for that one tool, with its own auth pattern, its own error handling, built again from scratch for the next tool, and the one after that.

## Line 4 -- Mechanism B (MCP way)
The MCP way: one standard protocol, one gateway, and every tool behind it becomes reachable through the same connection, already built, already authorized.

The tell is simple: count how many hours your last custom tool integration actually took, start to working. Multiply that by however many tools your agent is supposed to eventually reach.
