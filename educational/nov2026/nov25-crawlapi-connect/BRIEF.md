8 beats / 8 Kokoro audio lines, mirroring nov20's structure:
1. Hook -- adding a scraping layer sounds like standing up new infrastructure.
   Usually it doesn't have to.
2. Two fundamentally different ways a scraping tool can integrate, only one
   adds real infrastructure weight.
3. The fear -- new service, new infrastructure, a proprietary SDK to learn.
4. The actual pattern -- one API key, standard REST, or the same key through
   MCP for an agent.
5. The test -- does adopting this tool require a new service, or just a new
   API key?
6. Grounding -- Crawl API: standard JSON over REST, same key for MCP, no new
   infrastructure.
7. Reframe -- a scraping layer that needs its own infrastructure isn't
   actually simplifying anything.
8. Close + follow CTA.
